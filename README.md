# Homebrew tap for MyLoDB

```sh
brew tap farookhridoy/mylodb
brew install --cask mylodb
```

MyLoDB is a MySQL, MariaDB and SQLite manager for macOS. The app lives at https://github.com/farookhridoy/mylodb. It is not notarised by Apple; the cask removes the download flag so it opens normally. The app updates itself, so `brew upgrade` is not needed.
